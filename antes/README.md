# antes/

Acá guardé todo lo que hicimos antes de arrancar el sistema de cotizaciones con FastAPI.
No se borra nada: es la historia del proyecto y lo que ya se entregó.

| Qué hay | Qué es |
|---|---|
| `hotel.py`, `habitacion.py`, `pasajero.py`, `proveedor.py`, `reserva.py`, `usuario.py` | Las primeras clases en POO que hicimos para entender el negocio. |
| `index.html`, `estilos-cotizador.css` | El primer boceto de la página del cotizador. |
| `modulo_pasajeros/` | El módulo de escritorio (Tkinter + MySQL) que entregué en la GA7-AA3. |

La entrega de la GA7-AA3 quedó marcada con la etiqueta de Git `aa3-pasajeros`.
Para verla tal como se entregó en GitHub:
https://github.com/ElAlejo02/app-Reservas-G1/tree/aa3-pasajeros/modulo_pasajeros

Ojo: si usabas el entorno virtual `.venv` de `modulo_pasajeros`, al mover la carpeta
se daña. Para volver a correr ese módulo, borrá `.venv` y crealo de nuevo.
