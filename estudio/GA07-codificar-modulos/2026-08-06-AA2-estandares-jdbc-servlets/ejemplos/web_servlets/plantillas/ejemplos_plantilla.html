{# Equivalencias de JSP (lo que el instructor mostró en 4 páginas) con Jinja2: Directiva <%@ page import="java.util.Date" %> -> no hace falta: los datos llegan desde main.py Expresión <%= new Date() %> -> {{ ahora }} Scriptlet <% for (int i=1; i<=5; i++) { %> -> {% for i in range(1, 6) %} Declaración <%! int suma(int a, int b) {...} %> -> {% macro suma(a, b) %} Es un comentario de Jinja: no aparece en la página que recibe el navegador. #} Ejemplos de plantillas

Expresiones (una sola línea)

La fecha de hoy es: {{ ahora.strftime("%Y-%m-%d %H:%M") }}

Nombre en mayúsculas: {{ nombre | upper }}

Suma directa: {{ a + b }} · ¿a es mayor que b? {{ a > b }}

Scripts (varias líneas: un ciclo)

    {% for i in range(1, 6) %}
  • Habitación {{ 100 + i }}
    • {% endfor %}

Declaraciones (una función reutilizable)

{% macro suma(x, y) %}{{ x + y }}{% endmacro %}

La suma es {{ suma(a, b) }}
