# Material de estudio · ADSO Grupo 1 · Sistema de reservas hoteleras

Guías de estudio armadas a partir de las grabaciones de clase y las guías de aprendizaje del SENA (programa 228118, proyecto "Construcción de software integrador de tecnologías orientadas a servicios"). Todo lo que en clase se hace en Java aquí está explicado y construido en **Python**.

- [Stack Python del proyecto y equivalencias con Java](stack-python.md)
- [Librerías](requirements.txt)
- Ruta de estudio por temas con cursos de Platzi y YouTube: Word en tu PC, `Claude\Projects\Sena\Ruta de estudio\`

## Cómo está organizado

```
estudio/
├── README.md                          este índice
├── stack-python.md                    qué usamos en Python en vez de Java
├── requirements.txt
├── GA06-estructura-datos-e-interfaz/  1 clase
├── GA07-codificar-modulos/            9 clases: Git, JDBC, escritorio, POO, React, APIs
├── GA08-integrar-modulos-y-movil/     2 clases: integración y APK
│   └── 2026-10-07-AA1-.../            una carpeta por clase
│       ├── README.md                  guía de estudio de la clase
│       ├── ejemplos/                  código que se puede ejecutar (probado)
│       ├── capturas/                  pantallazos de los ejemplos
│       └── repaso-anki.csv            tarjetas para Anki
```

Cada guía de clase trae: resumen, conceptos explicados, qué se hizo en Java y cómo se hace en Python, checklist de evidencias, aplicación al sistema de reservas, plan de estudio, código explicado parte por parte y preguntas de repaso.
